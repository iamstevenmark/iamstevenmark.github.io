A Windows 11 Tutorial: How To Back Up or Restore All Drivers Using Line Commands

Purpose:
Your Windows OS is new or has been refreshed to pristine operating condition with all its device hardware. Learn to back up or restore all the drivers in a ready to use package for the next time you reinstall Windows. If you have many Windows PCs to maintain or periodically refresh only a few, you'll appreciate the value of these instructions. Easily back up or restore all the drivers with the following line command instructions.

• Prepare a Partition at the end of your Hard Drive:
Save time and effort by creating a partition - about 12GB in size - at the end of the PC's Hard Drive. We'll refer to this partition as the X: drive. Here you'll copy all the Windows drivers (which use about 800MB), a copy of these instructions, the Windows installation image that can be downloaded from the Microsoft Creation Tool app, and the USB/portable storage utility called Rufus. Relegating a part of each PC's hard drive for this purpose is for simplicity and not having to hunt around for the necessary files when you want to refresh Windows on a specific PC. To create the partition, use Windows Disk Management or your favorite partition manager. As the information is readily available online, I won't explain partition creation, disk management, getting the Windows installation image, or using Rufus. Optionally, save all the files of this partition to portable storage, which can be mounted and used in lieu of the partition.

• Copy All Device Drivers:
Press Ctrl+R keys to bring up the Windows Run popup where you type cmd and press Enter to open the command prompt window, a.k.a., Terminal.
There, to use the following command to copy all Windows device drivers to the-folder-you-name on the partition you created which we'll assign in Windows Disk Management as the X: drive, type:
dism /online /export-driver /destination:X:\the-folder-you-name

• Install All Device Drivers:
Press Ctrl+R keys to bring up the Windows Run popup where you type cmd and press Enter to open the command prompt window, a.k.a., Terminal.
There, to use the following command to install all Windows device drivers to the-folder-you-name on the partition you created which we'll assign in Windows Disk Management as the X: drive, type:
pnputil /add-driver "X:\the-folder-you-name\*.inf" /subdirs /install /reboot

• Extra #1 - Generate a List of All Your Windows Drivers:
Press Ctrl+R keys to bring up the Windows Run popup where you type cmd and press Enter to open the command prompt window, a.k.a., Terminal. Type ps and press Enter to start Powershell. Then at the user prompt PS C:\Users\your-username>, to get a printable list of drivers, type:
Get-WmiObject Win32_PnPSignedDriver| select DeviceName, Manufacturer, DriverVersion

• Extra #2 - Hide the Recovery Partition When Its Not Needed:
Use Windows Disk Management to remove the drive letter of the partition to hide it from File Explorer for later when needed.

• Extra #3 - Another Way to Open a Command Prompt Window:
Right-mouse-click on the Windows Start menu button and click on Terminal (Admin) to open it. Type exit to close it.
